# Technical SEO Checklist

Walk this checklist during the **Crawl** (Quick) or **Technical** (Full) phase. Mark each item Pass, Fail, or NA with the specific URL and evidence.

| # | Check | What to Look For | How to Verify | Severity |
|---|-------|-----------------|---------------|----------|
| 1 | **HTTPS enabled** | All pages load over HTTPS. No mixed content warnings (HTTP resources on HTTPS pages). HTTP requests redirect to HTTPS. | Load the site with `https://`. Check for mixed content in browser DevTools Console. Try `http://` — it should 301 to `https://`. | Critical |
| 2 | **robots.txt exists and is valid** | File at `/robots.txt`. Not blocking important pages or entire sections. `Sitemap:` directive pointing to the sitemap. No syntax errors. | Fetch `https://domain.com/robots.txt`. Verify important paths (homepage, product pages, blog) are not Disallowed. Check for `Sitemap:` line. | High |
| 3 | **sitemap.xml exists** | Valid XML sitemap at `/sitemap.xml` or the URL in `robots.txt`. Lists all important public pages. Each URL has `<lastmod>` date. No 404/500 URLs in the sitemap. | Fetch the sitemap URL. Validate XML structure. Spot-check 5 URLs — they should return 200. Check `<lastmod>` dates are present and recent. | High |
| 4 | **Mobile-friendly** | `<meta name="viewport" content="width=device-width, initial-scale=1">` present. No horizontal scroll at 360px. Text readable without zooming. Touch targets ≥ 24px (WCAG 2.2 AA). | Check viewport meta tag in `<head>`. Resize browser to 360px — no overflow. Use Chrome DevTools device toolbar (Ctrl+Shift+M) to test at 360px, 390px, and 414px. Google's Mobile-Friendly Test was retired in December 2023 — use Lighthouse mobile audit instead. | Critical |
| 5 | **Canonical tags** | Every page has `<link rel="canonical" href="...">` pointing to the preferred URL. Self-referencing canonicals on pages without duplicates. No conflicting canonicals. | Check `<head>` for `<link rel="canonical">` on each page. URL in the tag matches the page's preferred URL (with or without trailing slash, www vs non-www). | High |
| 6 | **Clean URL structure** | URLs are lowercase, hyphenated, readable. No unnecessary query parameters, session IDs, or tracking params in indexed URLs. Consistent trailing slash policy. | Review the URL patterns from the sitemap or crawl. Flag: uppercase letters, underscores, parameter chains (`?id=123&sort=asc`), or `.html`/`.php` extensions on modern frameworks. | Medium |
| 7 | **Proper status codes** | Missing pages return 404 (not 200 with "page not found" content — that's a soft 404). Moved pages return 301. No redirect chains (A→B→C). No redirect loops. | Request a known-missing URL — check status code. Follow redirects and count hops (max 2). Check the sitemap for URLs that don't return 200. | High |
| 8 | **Page speed** | Pages load quickly. Time to First Byte < 800ms. Largest Contentful Paint < 2.5s. No enormous uncompressed resources. | Run PageSpeed Insights: https://pagespeed.web.dev/ for homepage + 2 key pages. Record LCP, INP, CLS scores for mobile and desktop. | High |
| 9 | **Core Web Vitals** | LCP < 2.5s (good), INP < 200ms (good), CLS < 0.1 (good). Check both field data (CrUX) and lab data (Lighthouse). | PageSpeed Insights shows field data if available (real Chrome users). Lab data from Lighthouse. Field data is authoritative; lab data is directional. | High |
| 10 | **No orphan pages** | Every important page is linked from at least one other page on the site. No pages reachable only via direct URL or sitemap. | Cross-reference sitemap URLs with internal links found during crawl. Flag pages in the sitemap that no other page links to. | Medium |
| 11 | **Crawl depth** | Important pages are within 3 clicks of the homepage. Deep pages (4+ clicks) are less likely to be crawled and indexed. | From the homepage, count clicks to reach key pages (product, pricing, about, blog posts). Flag anything deeper than 3. | Medium |
| 12 | **No duplicate content** | No two pages have the same or very similar `<title>` and content. If duplicates exist, canonicals point to the preferred version. | Compare `<title>` tags across all crawled pages. Flag duplicates. Check if canonical tags resolve the duplication. | High |
| 13 | **Internationalization** | `<html lang="en">` (or appropriate language) is set. If multi-language: `<link rel="alternate" hreflang="x">` tags on each version. | Check `<html>` tag for `lang` attribute. If the site has language variants, check for `hreflang` tags in `<head>` and reciprocal linking. | Medium |
| 14 | **Server response time** | TTFB (Time to First Byte) < 800ms for the homepage and key pages. | Measure with `curl -o /dev/null -w "%{time_starttransfer}" https://domain.com` or PageSpeed Insights TTFB metric. | Medium |
| 15 | **Render strategy** | Public pages that need to rank have their main content in the initial HTML response (server-rendered or static). Client-only rendered pages are invisible to crawlers that don't execute JS. | View page source (Ctrl+U) on key public pages. If the main content (headings, text, product info) is NOT in the source HTML, it's client-rendered and at risk. | Critical |
